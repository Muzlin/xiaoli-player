# 🎬 小李播放器 (XiaoLi Player)

> 跨平台媒体播放器 · B站搜索 / 弹幕 / 下载 / AI字幕 / 桌面字幕 / 投屏 / 看屏 / 流畅直播 60+ 功能

**小李播放器**是一款功能丰富的跨平台媒体播放器，配套自建平台服务端，支持视频点播、弹幕互动、直播推流、兑换币经济系统等一整套玩法，适合小圈子自建视频社区。

---

## ✨ 功能特性

| 分类 | 功能 |
|---|---|
| 🎞️ 播放 | 在线点播 · B站视频搜索/下载 · 弹幕 · 倍速 · 记忆播放 · 播放列表 |
| 🧠 AI | AI 字幕生成 · AI 字幕翻译 · 桌面悬浮字幕 |
| 📡 直播 | 流畅 H.264 直播（推流工具一键开播）· 弹幕直播 · 直播回放 |
| 📱 设备 | 多端同步 · 投屏/广播 · 远程看屏（实时画面+录制+回放）· 指令下发 |
| 🪙 社区 | 兑换币经济 · 投币/点赞/收藏 · 每日签到 · 排行榜 · VIP · 定向发币/空投 |
| 🛡️ 管理 | 网页经济管理台 · 封号/临时封禁 · 防外挂检测 · 数据看板 · 全量备份 |
| 🔧 内容 | 课件转幻灯片(PPT/PDF/希沃enbx) · 视频抽帧 · 贴纸 · 公告/违禁词 |

## 📦 客户端支持平台

Flutter 跨平台构建：**Android · Windows · macOS**（另有 Web 网页体验版）。

## 🚀 下载安装

| 平台 | 方式 |
|---|---|
| 最新版 | [GitHub Releases](https://github.com/Muzlin/xiaoli-player/releases/latest) |
| 网页体验版 | 平台 `/` 首页在线看（无需安装） |
| Windows 一键安装 | `安装小李播放器.bat`（自动下载安装） |

> 客户端更新检测走「平台源 + GitHub」多源并行，发布新版本到 Releases 后客户端自动提示更新。

## 🧱 项目结构

```
client/     Flutter 客户端（Android / Windows / macOS / Web）
backend/    平台服务端（Python 标准库 http.server，零第三方依赖）
docs/       文档
version.json 客户端版本信息（更新检测用）
```

## 🔒 隐私与安全

- 平台活动日志上报 GitHub 前会**脱敏**（uid 加盐哈希、丢弃视频标题与设备名）
- 管理台仅本机/密钥可访问，支持异地强密钥鉴权
- 管理员操作全程审计（admin_audit.log）
